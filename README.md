# TEST Studio｜平面設計接案作品集

平面設計師 TEST 的個人接案網站。這是一個單頁式 Landing Page，展示品牌識別、包裝設計與社群視覺作品，並引導潛在客戶來信洽談合作。

---

## 專案概述

### 這個專案做什麼

這個網站把設計師的定位、代表作品與聯繫方式放在同一頁。訪客從上往下捲動，就能依序了解「我是誰 → 我做過什麼 → 怎麼找我」：

| 區塊 | 內容 |
| --- | --- |
| **導覽列** | 固定在頁面頂部的毛玻璃導覽列，點擊可平滑捲動到「作品」或「聯繫」 |
| **英雄區塊** | 接案狀態標籤、主標題、自我介紹、兩個 CTA 按鈕（與我聯繫／觀看作品），以及成果數據 |
| **精選作品** | 三張作品卡片（品牌識別、包裝、社群企劃），每張有專案類別、名稱與設計理念，滑鼠移入時卡片會浮起 |
| **聯繫區塊** | 邀請合作的文案，加上一個「寄信給我」按鈕 |
| **頁尾** | 版權資訊與 Instagram、Behance、Dribbble 連結 |

### 解決什麼問題

接案設計師常把作品分散在各個社群平台，客戶很難在短時間內判斷「這個人適不適合我的專案」。這個網站提供一個**可以直接分享的單一網址**：

- **快速建立第一印象**：用品牌漸層色與排版，直接展現設計師的風格。
- **縮短決策路徑**：頁面上每個 CTA 都導向聯繫方式，減少客戶流失。
- **手機也好讀**：大多數客戶是從社群點進來、用手機瀏覽，所以版面針對小螢幕做了優化。
- **零維護成本**：純靜態網頁，不需要後端或資料庫，可以免費部署到任何靜態網站託管服務。

### 設計細節

- **RWD 響應式**：900px 以下作品卡片改為單欄；600px 以下隱藏導覽連結，按鈕改成滿版垂直排列。
- **觸控友善**：手機版所有按鈕與連結的最小高度都是 44px。
- **淡入動畫**：頁面載入時各區塊依序淡入上浮；如果系統開啟「減少動態效果」，動畫會自動停用。

## 安裝與執行

這個專案**不需要安裝任何套件、也不需要建置**，只要有 Git 和瀏覽器就能執行。

### 事前準備

- [Git](https://git-scm.com/downloads)（用來下載專案；也可以改用下方的 ZIP 下載方式）
- 任一現代瀏覽器：Chrome、Edge、Safari 或 Firefox

### 步驟 1：下載專案

在終端機執行：

```bash
git clone https://github.com/yellow598/claude-lab.git
cd claude-lab
```

> 如果沒有安裝 Git：到 GitHub 專案頁面點選綠色的 **Code → Download ZIP**，下載後解壓縮即可。

### 步驟 2：開啟網站

**方法 A：直接開啟（最簡單）**

在資料夾中雙擊 `index.html`，或把檔案拖進瀏覽器視窗。

**方法 B：用本機伺服器開啟（比較接近正式上線的環境）**

如果電腦已經安裝 Python 3，在專案資料夾執行：

```bash
python -m http.server 8000
```

接著用瀏覽器打開 <http://localhost:8000>。要停止伺服器時，在終端機按 `Ctrl + C`。

> 字型需要網路連線才能從 Google Fonts 載入；離線時會自動改用系統預設字型，版面不會壞掉。

### 步驟 3：預覽手機版

1. 在瀏覽器按 `F12` 開啟開發者工具。
2. 按 `Ctrl + Shift + M`（Mac 是 `Cmd + Shift + M`）切換到裝置模擬模式。
3. 在上方選擇 **iPhone SE**，或把寬度設為 **375px**。

### 步驟 4：修改內容

所有文字與樣式都在 `index.html` 裡：

- **文字內容**：在 `<body>` 區塊中直接修改。
- **品牌色**：修改 `<style>` 開頭 `:root` 裡的 CSS 變數，例如 `--brand-gradient`、`--bg-0`。

存檔後，重新整理瀏覽器就能看到修改結果。

## 技術架構

| 技術／服務 | 負責的工作 |
| --- | --- |
| **HTML5** | 網頁結構。使用 `header`、`nav`、`main`、`section`、`article`、`footer` 等語意化標籤，讓搜尋引擎和螢幕閱讀器更容易理解頁面 |
| **CSS3** | 全部視覺與版面，直接寫在 `index.html` 的 `<style>` 中 |
| ├ CSS 變數 | 集中管理品牌色、背景色、標題字級與最小觸控尺寸，換色只要改一個地方 |
| ├ Flexbox／Grid | 導覽列、按鈕群組、數據列的排列用 Flexbox；作品卡片的三欄版面用 Grid |
| ├ Media Queries | 在 900px 和 600px 兩個斷點調整版面，並偵測 `prefers-reduced-motion` 來關閉動畫 |
| ├ `@keyframes` 動畫 | 各區塊載入時依序淡入上浮 |
| └ `backdrop-filter` | 導覽列的毛玻璃半透明效果 |
| **Google Fonts** | 提供網頁字型：**Inter**（英文與數字）、**Noto Sans TC**（繁體中文） |
| **內嵌 SVG** | 按鈕箭頭與作品卡片圖示，不需要額外的圖片檔，也能跟著文字顏色變色 |
| **Git／GitHub** | 版本控制與原始碼託管 |

本專案**不使用任何 JavaScript、前端框架或建置工具**，因此載入速度快，也沒有需要維護的套件相依問題。
